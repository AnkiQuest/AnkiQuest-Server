# Generated poses

Anki-tan by Shigeyuki (https://www.patreon.com/Shigeyuki).

`frozen-full.png` and `frozen-chibi.png` are generated derivatives of his Anki-tan asset
pack, licensed CC BY-SA 4.0 under [LICENSE](../LICENSE).
Generated with OpenAI's `image_gen` tool; its model identifier was not exposed.

[Prompts, selection and cleanup](../../../docs/branding/core-poses-2026-11/README.md)
describe the changes. Original pack files are not replaced.

[Full-size additions](../../../docs/branding/ankitan-full-2026-11/README.md)
record the later asleep, sad and neglected poses. Streak remains outstanding.

Their earlier generated file names are preserved byte for byte in
[archive](../archive/README.md); active masters use the core pose names.
